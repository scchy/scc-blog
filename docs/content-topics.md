# 博客内容规划：四大主题

> 博客内容围绕四大主题展开。每篇文章应归入对应主题，并在 `tags` 中加入该主题的关键标签。

## 1. 强化学习（RL）

**定位**：算法原理 + 工程实践 + 论文解读

- 马尔可夫决策过程（MDP）、贝尔曼方程
- 策略梯度、Q-Learning、DQN
- 深度强化学习：PPO、SAC、TD3
- 多智能体强化学习（MARL）
- RL 在推荐、控制、游戏中的应用

**推荐标签**：`RL`、`强化学习`、`MDP`、`PPO`、`DQN`

## 2. LLM + Agent

**定位**：大模型应用 + Agent 工程 + 架构设计

- Prompt Engineering、Few-shot、CoT
- RAG（检索增强生成）
- Agent 架构：ReAct、工具调用、多智能体协作
- Function Calling、MCP
- LLM 应用落地、评估与成本优化

**推荐标签**：`LLM`、`Agent`、`大模型`、`RAG`、`Prompt`

## 3. 机器学习与深度学习（ML + DeepLearning）

**定位**：经典 ML + 深度学习 + 训练优化

- 传统机器学习：线性模型、树模型、SVM、聚类
- 神经网络基础、CNN、RNN、Transformer
- 特征工程、模型评估、调参
- 分布式训练、推理优化、量化

**推荐标签**：`ML`、`深度学习`、`机器学习`、`神经网络`、`Transformer`

## 4. 亲子成长（Parenting）

**定位**：家庭教育 + 英语启蒙 + 亲子互动

- 亲子英语学习（分级阅读、磨耳朵、自然拼读）
- 儿童教育游戏（桌游、编程启蒙、益智游戏）
- 家庭教育方法、习惯培养、高质量陪伴
- 成长记录与反思

**推荐标签**：`亲子`、`英语学习`、`教育`、`游戏`、`家庭`

---

## 写作规范

1. 每篇文章在 frontmatter 的 `tags` 中加入对应主题标签
2. 主题页 `/topics` 会自动按标签统计文章数
3. 一篇文章可归入多个主题（打多个标签即可）
4. 站务/元内容（如博客搭建）可不归入四大主题
