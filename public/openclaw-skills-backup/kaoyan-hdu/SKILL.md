# 考研杭电管理工具（`/ky`）

## 数据文件位置
所有数据存放在 workspace `memory/` 目录下：

| 文件 | 用途 |
|------|------|
| `memory/kaoyan-hdu-checkins.md` | 打卡记录 |
| `memory/kaoyan-hdu-plan.md` | 学习计划 |
| `memory/kaoyan-hdu-status.md` | 状态概览（自动维护） |

## 命令处理

### `/ky` 或 `/ky help`
显示帮助信息，列出所有可用命令。

### `/ky 打卡 [内容]`
1. 获取当前日期（Asia/Shanghai 时区）
2. 如果用户提供了内容，直接记录
3. 如果没有提供，询问用户今日学习内容
4. 格式：`YYYY-MM-DD | 科目 | 具体内容 | 时长`
5. 追加到 `memory/kaoyan-hdu-checkins.md`
6. 更新 `memory/kaoyan-hdu-status.md` 的统计数据
7. 回复确认信息，包含连续打卡天数

打卡记录格式示例：
```
| 2026-04-29 | 数学 | 微积分第三章复习 | 2.5h |
| 2026-04-29 | 英语 | 背单词List 5 | 1h |
```

### `/ky 状态`
1. 读取 `kaoyan-hdu-checkins.md` 统计：
   - 总打卡天数（去重日期）
   - 连续打卡天数（从今天往前数）
   - 最长连续记录
   - 本周打卡天数
2. 读取 `kaoyan-hdu-plan.md` 判断当前所处阶段：
   - 根据当前日期匹配五阶段时间轴
   - 计算阶段进度（第几周/总周数）
   - 读取检查点日历，标记 passed/upcoming
3. 统计各科实际投入时长 vs 计划投入
4. 计算距离考试天数（2026-12-26）
5. 生成状态卡片回复

状态回复格式：
```
📊 考研杭电学习状态
━━━━━━━━━━━━━━━━━━
📅 总打卡：{n}天
🔥 连续：{n}天（最长：{n}天）
📈 本周：{n}/7天
⏱️ 总时长：{n}小时

📍 当前阶段：{阶段名}（{日期范围}）
📅 阶段进度：第{X}周 / 共{Y}周
🎯 距离考试：{n}天

📚 最近打卡：
• 04-29 数学 微积分 2.5h
• 04-28 英语 单词 1h
...

🎯 检查点：
🔴  upcoming  {日期} {检查点名称}
🟡  passed     {日期} {检查点名称}

📊 科目投入：
• 数学：{实际}h / 计划{计划}h
• 专业课：{实际}h / 计划{计划}h
• 英语：{实际}h / 计划{计划}h

💪 加油！坚持就是胜利！
```

### `/ky 计划` 或 `/ky 进度`
基于 `memory/kaoyan-hdu-plan.md` 中的五阶段备考计划，智能输出当前/下周计划。

**无参数时**：
1. 读取 `kaoyan-hdu-plan.md` 中的五阶段时间轴
2. 根据当前日期判断所处阶段：
   - 阶段一 基础重建（5.05-7.31）
   - 阶段二 强化攻坚（8.01-10.15）
   - 阶段三 真题突破（10.16-11.15）
   - 阶段四 冲刺模考（11.16-12.20）
   - 阶段五 考前调整（12.21-12.25）
3. 显示当前阶段的核心任务表
4. 读取打卡记录，统计各科实际投入时间
5. 对比计划 vs 实际，生成下周每日安排（区分工作日/周六/周日家庭日）
6. 输出格式：
```
📋 智能学习计划（基于备考文档）
━━━━━━━━━━━━━━━━━━
📍 当前阶段：阶段一 基础重建（5.05-7.31）
📅 阶段进度：第X周 / 共13周

📊 本周实际投入：
• 数学：Xh（计划128h/阶段，已投入Xh）
• 专业课：Xh
• 英语：Xh

📅 下周计划（05.05-05.11）：
工作日：
  早间 6:30-7:30  数学-极限与连续
  碎片 8:00-9:00  墨墨背单词
  晚间 22:00-23:30 数学-300题
周六：
  上午 8:30-11:30 数学套卷
  下午 14:00-17:00 数据结构-线性表
周日：家庭日 🏠

⚠️ 检查点提醒：6.15 高数极限→积分需完成
```

**有参数时**：
- 直接更新 `kaoyan-hdu-plan.md` 中的具体条目
- 支持标记完成：`/ky 计划 完成 高数极限`
- 支持添加备注：`/ky 计划 备注 定积分换元法需加强`
- 支持修改安排：`/ky 计划 调整 下周数学改为微分学`

### `/ky 检查点`
显示检查点日历及达标状态：
1. 读取 `kaoyan-hdu-plan.md` 中的检查点表格
2. 对比打卡记录和计划进度
3. 输出：
```
🎯 关键检查点
━━━━━━━━━━━━━━━━━━
🔴  upcoming  6.15 高数极限→积分基础完成（还有X天）
🟡  passed     6.30 高数一轮+数据结构一轮
🔴  upcoming  7.31 线代基础+数据结构代码
...

📊 当前风险：数学进度滞后X天，建议...
```

### `/ky 周报`
1. 读取本周打卡记录
2. 统计各科时长分布
3. 与上周对比（如有数据）
4. 生成周报摘要

周报格式：
```
📋 本周学习周报（04.24-04.30）
━━━━━━━━━━━━━━━━━━
📅 打卡天数：{n}天
⏱️ 总时长：{n}小时

📊 科目分布：
• 数学：{n}h ({percent}%)
• 英语：{n}h ({percent}%)
• 专业课：{n}h ({percent}%)

📈 环比上周：+{n}h / -{n}h

🎯 下周建议：
• ...
```

### `/ky 调整 [内容]`
- 修改当前计划中的具体安排
- 例如：`/调整 周六加班 数学移至周五`
- 支持：日期调整、任务替换、时长修改

### `/ky 问 [科目] [题目/问题]`
- 学科答疑功能
- 调用搜索或知识库回答考研相关问题
- 支持科目：数学、英语、政治、专业课
- 如果问题复杂，建议用户详细描述或发图片
- 可以结合 wiki 知识库查询（如果已收录相关教材）

提问回复格式：
```
❓ 答疑：{问题摘要}
━━━━━━━━━━━━━━━━━━
💡 解答：...

📚 相关知识点：...
📝 建议：...
```

## 实现方式
使用 `read`/`write`/`edit` 工具操作上述 markdown 文件。
不需要额外脚本，纯文件操作即可。

## 首次使用
如果数据文件不存在，自动创建模板文件并提示用户开始记录。

## 注意事项
- 日期统一用 YYYY-MM-DD 格式
- 时长可以用 xh 或 x小时 格式
- 鼓励用户，回复中适当加入加油 💪🔥 等积极元素
